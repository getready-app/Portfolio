# Portfolio de Mohamed Aiteur

Site one-page statique en HTML, CSS et JavaScript natifs, avec une direction visuelle Black & Red. Il ne nécessite aucune dépendance à installer.

## Démarrer en local

Python 3 est requis pour lancer le serveur statique :

```bash
npm run dev
```

Le site sera disponible sur `http://localhost:4173`.

## Contenu

- Sections À propos, Compétences, Parcours, Projets et Contact.
- Basculer entre français et anglais, avec menu mobile.
- Projets documentés selon le CV et les sources vérifiées pour GetReady.
- Formulaire qui prépare un courriel dans l’application e-mail du visiteur sans envoyer le message.
- Illustrations CSS originales, réduites sur les petits écrans.
- Prise en compte de `prefers-reduced-motion`.
- CV original dans `public/CV-Mohamed-Aiteur.pdf` pour le téléchargement.

Les illustrations des projets sont des interprétations graphiques, pas des captures d’écran réelles.
